# UFO 飞船灯
参考用户飞船灯图片及标注图，保留扁碟船身、圆顶座舱和绿色锥形光束。船身改为封闭碟底，中央留向下出光孔。灯罩底圈完整，无走线凹槽。灯组安装在飞碟内部。

船身沿腰线水平分上下两半，使用两对磁铁连接；上下盖各留两个Ø7.1 mm、深1.1 mm圆形盲槽。默认孔中心x=±46 mm、y=0，对齐z=156 mm接缝。槽孔直接采用指定尺寸，不另加旷量。上下外缘等厚，接缝在外缘正中间；上下直边高度均为2 mm，径向壁厚均为4.8 mm（向内加厚一倍，外径不变），上下倒角各高1 mm，连同直边的总边缘高6 mm。三个外观组件（船身、座舱、灯罩）细分为四个主要装配打印件：上壳、下壳、座舱、灯罩；另提供一个无镂空备用灯罩，以及八个独立半球推进器，共十三个打印件，另需四枚圆片磁铁。座舱罩与上壳取消全部螺纹，直接落座，可竖直取下。上盖内圈台阶向下延伸至与外圈接合面齐平，默认延伸13.6 mm，保留Ø63.6 mm中央通孔。

用户灯组直径60 mm、厚8 mm，61 mm内槽预留装配余量，默认朝下，从56 mm出光孔照进绿色灯罩。允许同一灯组翻面朝上，光线经中央通道进入座舱；朝上时座舱使用半透明材料，实际透光性需样件验证，非同时双向发光。

灯组承托边和完整定位环均位于下半壳，内径61 mm、有效槽高9 mm；承托及定位模组整体下移，环顶与下壳边缘齐平，默认承托面高147 mm、环顶高156 mm；中央环外侧台阶抬平，外径74 mm、内径61 mm。内部走线采用6 mm宽、4 mm深向上敞开的平底矩形凹槽，槽深为下盖外缘2 mm半缺口的两倍；槽底高152 mm，槽中心高154 mm；出线口位于后侧边缘接缝，上下壳各开宽6 mm、高2 mm的半缺口，合成6×4 mm方口；下半口向上开放，可铺线后合壳。方口已检查3.6 mm圆线出口局部包络；原配线径及弯曲半径仍需试装核对，不经过灯罩。外壳仅适配用户给定灯组包络，无控制板、无需自制PCB，不改变灯组原有电源系统。

保留默认船身外径150 mm、灯罩锥体高140 mm和底径114 mm，总高206 mm；两款灯罩锥形侧壁均按下端基准采用1.2 mm恒定径向壁厚（垂直锥面约1.191 mm），内外锥面平行；顶部保留1.2 mm薄承托肩面、插颈长4 mm、颈壁2.5 mm、单边插接间隙0.3 mm。座舱罩下端无凸圈，底缘为平整承托面；飞碟上壳向上形成外径68.4 mm、高5 mm、壁厚2.4 mm的光滑定位圈，嵌入座舱内径69.1 mm、深5.5 mm导向孔，单边间隙0.35 mm，定位圈顶部导入倒角0.5 mm；靠重力落座，无锁止。下壳边缘径向壁厚4.8 mm，安装推进器的锥形环壁默认法向厚3.2 mm；内部两个磁铁座采用圆端支座，与中央环之间填实；磁铁粘接固定，装配前核对两对磁极相吸，孔位需按实物试配，磁吸保持力待实测。灯罩承重肩面靠重力落座，不从飞碟提起整灯。

交付独立实体的STEP装配模型；模型不是电气或热性能实测记录。

下壳底部八个半球推进器均为独立分件，默认直径16 mm，沿半径60 mm圆周每45°均布，起始角22.5°以避开后侧出线孔，朝向底面斜面法线。每个半球接触圆面同轴延长1.5 mm，形成直径16 mm圆柱插接段；下壳对应直径16.5 mm、轴向深1.5 mm盲孔，直径总间隙0.5 mm（单边0.25 mm）。孔深以原球心所在底面局部切平面为基准，孔底由连续加厚锥形环壁支撑，保留至少1.2 mm材料，内侧没有独立圆盘凸起。间隙配合没有锁止，建议少量兼容PETG的胶固定。独立半球可用插接段平底朝下打印。

灯罩正面下部按用户最新黄底黑色奶牛剪影图描取完整轮廓，并左右镜像，使牛头朝右。保留原图轮廓转角、牛角、耳朵、四条腿、乳房及下垂尾巴，无内部斑块或眼睛。默认宽32 mm、高约19.88 mm（旋转前），按原图比例缩放，中心距底部38 mm，头朝右上倾斜18°。只切穿正面薄壁，背面和底圈完整，灯罩仍为一个打印件。镂空上沿及细节需切片检查支撑；细尾、乳头及腿间细节的还原度待样件验证。

额外增加一个同尺寸无奶牛镂空的绿色灯罩，基体截面、壁厚和插颈与原灯罩一致，可替换使用。原奶牛灯罩保留；备用灯罩默认放在右侧x=160 mm、y=0、z=0处并排展示。
