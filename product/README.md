# UFO 飞船灯
参考用户飞船灯图片及标注图，保留扁碟船身、圆顶座舱和绿色锥形光束。船身改为封闭碟底，中央留向下出光孔。灯罩底圈完整，无走线凹槽。灯组安装在飞碟内部。

船身沿中间分两半，由两个内部方块连接；默认按腰线水平上下分壳、两枚独立插块实现。三个外观组件（船身、座舱、灯罩）细分为六个装配打印件：上壳、下壳、两个插块、座舱、灯罩；另提供一个无镂空备用灯罩，共七个打印件。座舱罩与上壳取消全部螺纹，直接落座，可竖直取下。

用户灯组直径60 mm、厚8 mm，61 mm内槽预留装配余量，默认朝下，从56 mm出光孔照进绿色灯罩。允许同一灯组翻面朝上，光线经中央通道进入座舱；朝上时座舱使用半透明材料，实际透光性需样件验证，非同时双向发光。

灯组承托边和完整定位环均位于下半壳，内径61 mm、有效槽高9 mm。内部穿线洞改为6 mm宽向上敞开的U形凹槽；出线口改到下半壳后侧边缘，做成向上开放的直边方形缺口，底部原圆孔封回。默认宽6 mm、高4 mm，上壳形成平直上沿；可从上方铺线后合壳。方口已检查3.6 mm圆线出口局部包络；原配线径及弯曲半径仍需试装核对，不经过灯罩。外壳仅适配用户给定灯组包络，无控制板、无需自制PCB，不改变灯组原有电源系统。

保留默认船身外径150 mm、灯罩锥体高140 mm和底径114 mm，总高206 mm；灯罩薄壁1.2 mm、插颈长10 mm、颈壁2.5 mm、单边插接间隙0.3 mm。座舱罩采用68.4 mm光滑定位裙边，插入69.1 mm孔内约5 mm，单边间隙0.35 mm，导入倒角0.5 mm，底缘肩面承托；靠重力落座，无锁止。下壳连续薄壳默认2.4 mm；内部方块默认8×8×10 mm并带细修配筋，最大外宽8.28 mm配8.3 mm方孔；不带倒扣锁止，插接手感需试装校准。灯罩承重肩面靠重力落座，不从飞碟提起整灯。

交付独立实体的STEP装配模型；模型不是电气或热性能实测记录。

下壳底部按用户要求增设一圈八个半圆推进器装饰，默认做成与下壳一体的凸起半球，直径16 mm，沿半径60 mm圆周每45°均布，起始角22.5°以避开后侧出线孔。装饰沿底部斜面法线朝外，不增加独立打印件。半球下沿低于下壳中央环面，打印需支撑。

灯罩正面下部采用用户最新黑色奶牛剪影图片的完整轮廓贯穿镂空，保留牛角、耳朵、四条腿、乳房及上翘尾巴，无内部斑块或眼睛。直接从参考图描取平滑曲线，按原图比例默认宽32 mm、高约28.46 mm（旋转前），中心距底部38 mm，头朝右上倾斜18°。只切穿正面薄壁，背面和底圈完整，灯罩仍为一个打印件。镂空上沿及细节需切片检查支撑；细尾、乳头及腿间细节的还原度待样件验证。

额外增加一个同尺寸无奶牛镂空的绿色灯罩，基体截面、壁厚和插颈与原灯罩一致，可替换使用。原奶牛灯罩保留；备用灯罩默认放在右侧x=160 mm、y=0、z=0处并排展示。
