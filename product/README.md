# UFO 飞船灯
参考用户飞船灯图片及标注图，保留扁碟船身、圆顶座舱和绿色锥形光束。船身改为封闭碟底，中央留向下出光孔。灯罩底圈完整，无走线凹槽。灯组安装在飞碟内部。

船身沿中间分两半，由两个内部方块连接；默认按腰线水平上下分壳、两枚独立插块实现。三个外观组件（船身、座舱、灯罩）细分为六个打印件：上壳、下壳、两个插块、座舱、灯罩。座舱与上壳原有螺旋螺纹保留。

用户灯组直径60 mm、厚8 mm，61 mm内槽预留装配余量，默认朝下，从56 mm出光孔照进绿色灯罩。允许同一灯组翻面朝上，光线经中央通道进入座舱；朝上时座舱使用半透明材料，实际透光性需样件验证，非同时双向发光。

灯组承托边和完整定位环均位于下半壳，内径61 mm、有效槽高9 mm。内部穿线洞改为6 mm宽向上敞开的U形凹槽；后侧外缘出线口也移至下半壳并向上开放，合壳后由上壳盖住。装配时直接放灯、铺线，无需把插头穿过小孔。默认通道宽6 mm，实际引线外径仍需试装核对，不经过灯罩。外壳仅适配用户给定灯组包络，无控制板、无需自制PCB，不改变灯组原有电源系统。

保留默认船身外径150 mm、灯罩锥体高140 mm和底径114 mm，总高206 mm；灯罩薄壁1.2 mm、插颈长10 mm、颈壁2.5 mm、单边插接间隙0.3 mm。72 mm大径、3 mm螺距座舱螺纹保持原配合。下壳连续薄壳默认2.4 mm；内部方块默认8×8×10 mm并带细修配筋，最大外宽8.28 mm配8.3 mm方孔；不带倒扣锁止，插接手感需试装校准。灯罩承重肩面靠重力落座，不从飞碟提起整灯。

交付独立实体的STEP装配模型；模型不是电气或热性能实测记录。
