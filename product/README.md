# UFO 飞船灯
参考三张用户图片融合扁碟船身、圆顶座舱和锥形绿色光束。成品仅三个打印部件，底圈和插接颈均属于灯罩本体。座舱使用实际螺旋牙旋拧拆装；灯罩上端插入船身，肩面承载船身重量。

用户灯组包络为直径60 mm、厚8 mm。预留直径61 mm安装槽，底部出光口56 mm，灯组向下发光；从旋开的座舱口放入。灯组已有外壳、引线和供电系统，仅做机械适配，无控制板、无需自制PCB。灯组具体品牌、功率、插头未知，不推断电气接线；预留6 mm走线孔及灯罩底缘出口，先穿线再放灯。

默认尺寸：飞船外径150 mm，灯罩锥体高140 mm、底径114 mm；座舱高34 mm；总高约206 mm。灯罩1.2 mm薄壁，上端68 mm外径插颈长10 mm、壁厚2.5 mm，单边间隙0.3 mm。螺纹大径72 mm、螺距3 mm、旋合约3圈，单边放量0.35 mm。均可在CAD参数中修改。

默认PETG制作：船身银灰色，座舱暖黄色，灯罩半透明绿色。薄壁透光性、温升、螺纹和插接手感需实物试装；灯罩不用于提起整灯。只对给定灯组包络负责，不把假造灯组实体加入交付模型。

螺纹实现参考bd_warehouse官方API：https://bd-warehouse.readthedocs.io/en/latest/thread.html 。外形参考用户上传图片，不复制第三方原模型。交付三个独立实体的STEP装配模型。
