# 三件式 UFO 飞船灯

船身外径150 mm；锥形灯罩高140 mm，底径114 mm；总高206 mm。三件分别为银灰船身、暖黄座舱、半透明绿色光束灯罩。仅三件打印实体，未伪造灯组模型。用户灯组包络：直径60 mm、厚8 mm。

## Interfaces

- lamp_fit：船身中部61 mm安装槽，槽底z=153 mm；灯组占z=153–161 mm。56 mm出光口留下2 mm径向托边。可从约69 mm螺纹开口放入。走线孔直径6 mm，位于+x、中心距32 mm，贯通到下方灯罩；插颈对应处开6 mm宽、7 mm深避线槽。
- dome_thread：右旋真实螺旋牙，大径72 mm、螺距3 mm、有效段9 mm；外牙径向深1.8 mm、平顶0.6 mm。内牙径向放量0.35 mm、牙侧轴向放量0.25 mm，约旋转三圈。整体中空盖结构不属于独立标准螺钉，M72经screwjoint拒绝后记录free，采用bd_warehouse Thread构建两半。来源：https://bd-warehouse.readthedocs.io/en/latest/thread.html
- shade_insert：灯罩插颈外径68 mm、长10 mm，壁厚2.5 mm；船身孔68.6 mm，顶端余量0.8 mm，落在z=140 mm肩面上。此接口是滑动配合，依靠重力落座，不可握住飞船提起整灯。

## Making and assembly

默认0.4 mm喷嘴、0.16–0.20 mm层高。绿色灯罩锥面名义径向壁厚1.2 mm，垂直底圈落地打印，避免花瓶模式，因为插颈和避线槽需要普通切片。半透明绿色PETG；实际透光性依耗材而变。

船身与座舱使用PETG。船身底面朝下，碟翼下表面为开放减重腔，需要从打印平台生成可去除支撑；支撑避开灯槽、插接孔和螺纹牙面。座舱螺纹轴竖直、开口向下，圆顶内侧顶部及底部宽肩悬垂按切片预览增加支撑。打印后去毛刺，避免强拧。

装配顺序：先将灯组引线穿过船身6 mm孔，将灯组朝下放在环形托边；引线通过灯罩插颈避线槽进入锥体，并从底缘6×6 mm缺口引出。将船身落到灯罩肩面并对齐上部避线槽。保持引线远离螺纹，顺时针旋入座舱至肩面接触，勿过拧。逆向拆装可取灯组。

现有圆饼灯的品牌、功率及原配插头未给出，只校核用户提供包络；不指定电气针脚、不改装原电源。走线孔用于引线，不保证未测量插头能穿过。首件需验证螺纹配合、插接间隙、稳固性和点亮温升，尚无实物测试记录。
