# UFO 飞船灯：上下分壳

船身外径150 mm，灯罩锥体高140 mm、底径114 mm，装配总高206 mm。飞船本体、座舱、绿色灯罩是三个外观组件；按本次要求把飞船本体拆成上壳、下壳和两枚内部方形插块，所以交付共六个独立打印实体。

## Interfaces

- body_square_join：默认水平腰线z=156 mm分上下壳。两个独立方块中心x=±46 mm、y=0，长度10 mm，主体8×8 mm；导入倒角0.5 mm，四面细圆筋外凸0.14 mm，总包络8.28 mm。上下各8.3 mm方孔、深5.4 mm，名义总横向间隙0.02 mm，每侧插入约5 mm。用于插接定位，非倒扣锁止，拔脱力未实测；不要提上壳搬动整灯。此连接为free自定义打印插接结构。
- lamp_fit：灯组包络为用户指定直径60 mm、厚8 mm，安装在飞碟内部z=153–161 mm。承托边与完整定位环均在下半壳，内径61 mm、可用高度9 mm，灯座顶面z=162 mm，与座舱底端留0.5 mm轴向间隙。下壳保留56 mm下照出光口，周围连续封闭，无旧版开放减重腔。圆饼灯两面翻转不改变包络，默认向下照入绿色灯罩；朝上时经中央通道照向座舱，座舱必须用半透明材料才会显著透光。无双向同时照明或光效实测。
- cable：灯座后侧（-Y）保留6 mm宽向上开放U形槽，槽底z=150 mm、圆弧中心z=153 mm。外部出口位于下半壳后侧边缘，为半圆缺口，圆心在合壳面z=156 mm，宽6 mm、深3 mm，沿Y方向贯穿边缘壁。上壳形成平直上沿；底部原圆孔封闭。从上方放线，无需穿插头。出口局部2.6 mm圆线包络检查通过，半圆开口理论容纳最大3 mm圆线；实际线径和弯曲半径需试装核对。灯罩无走线缺口。
- dome_thread：保留右旋真实螺纹，大径72 mm、螺距3 mm、9 mm牙段；内牙径向放量0.35 mm、牙侧轴向放量0.25 mm。整体中空盖不是标准独立螺钉，前版已通过M72的screwjoint拒绝记录为free，继续使用bd_warehouse Thread。来源：https://bd-warehouse.readthedocs.io/en/latest/thread.html
- shade_insert：灯罩插颈68 mm外径、10 mm长、2.5 mm颈壁，配68.6 mm下壳孔，顶端余量0.8 mm；z=140 mm肩面承载。为重力落座滑动配合，非锁扣。

- underside_decor：下壳底部八个一体半球推进器装饰，直径16 mm，中心沿半径60 mm圆周每45°均布，起始角22.5°；球面朝向底部斜面外侧，根部嵌入下壳1.2 mm并融合，全部属于下壳单一实体。后侧出线孔位于两装饰之间。装配最低装饰点z=137.625 mm，低于下壳中央底环2.375 mm，但与灯罩留有径向空间。

## Making and assembly

默认0.4 mm喷嘴、0.16–0.20 mm层高。灯罩采用半透明绿色PETG，锥面径向名义壁厚1.2 mm；底圈朝下竖直打印，普通切片。透光性依耗材、层高及表面而变。

上、下壳使用银灰PETG。上壳以腰线接合面作为候选贴床面，内侧斜面及座舱接口悬空处按切片预览添加可去除支撑。下壳因灯座高出腰线，不能再以腰线面直接贴床；默认保持灯座朝上，新增半球装饰低于中央底环，不能再让中央底环直接贴床；切片时将整件置于支撑上，底部半球、外圈碟底与中央插颈内孔按预览添加可拆支撑及稳定底筏。半球可见面可能留下支撑痕，需要清理修磨；尚未实际切片或打印。开放分壳便于清理支撑，走线槽口及边缘半圆缺口去除毛刺并轻磨圆滑。支撑不得伤及方孔、灯槽及螺纹牙面。两枚小方块长度轴竖直打印，0.5 mm导角先进入孔，细筋用于局部修配。8.28/8.3 mm只是名义贴合配合，打印误差可能使其过紧或过松，应先试打一枚方块；修磨细筋或按实测调整方孔。不得强敲或假定插接能承受提拉整灯。

座舱保持螺纹轴竖直、开口向下；圆顶内侧顶部及宽肩悬垂按切片预览增加支撑。朝上照明选半透明暖黄色PETG。打印后清除毛刺和支撑，轻旋试配，勿过拧。

装配顺序：拆开飞碟上下壳；将发光面向下的灯组放入下壳完整灯座；从上方把引线铺入灯座后侧U形凹槽，在内腔保留弯曲余量后，经下半壳后侧边缘半圆缺口向外出线；将两枚方块插入下壳方孔，确认线材低于合壳面且无夹压后合拢上壳，旋上座舱，最后把下壳落到灯罩插颈肩面。更换为朝上照明时，先断电拆开两半，将圆饼灯翻面，整理原引线后重新合壳。

灯组品牌、功率和原配插头未知；仅验证给定机械包络，不指定电气针脚，不改装原电源。首件仍需验证插块拔脱力、螺纹手感、插颈配合、稳固性和点亮温升。尚无实物测试记录。
