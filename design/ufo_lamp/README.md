# UFO 飞船灯：上下分壳

船身外径150 mm，灯罩锥体高140 mm、底径114 mm，装配总高206 mm。飞船本体、座舱、绿色灯罩是三个外观组件；按本次要求把飞船本体拆成上壳、下壳和两枚内部方形插块，所以交付共六个独立打印实体。

- lamp_fit：灯组包络为用户指定直径60 mm、厚8 mm，安装在飞碟内部z=153–161 mm。承托边与完整定位环均在下半壳，内径61 mm、可用高度9 mm，灯座顶面z=162 mm，与座舱定位裙边底端留5 mm轴向间隙。下壳保留56 mm下照出光口，周围连续封闭，无旧版开放减重腔。圆饼灯两面翻转不改变包络，默认向下照入绿色灯罩；朝上时经中央通道照向座舱，座舱必须用半透明材料才会显著透光。无双向同时照明或光效实测。

## Making and assembly

默认0.4 mm喷嘴、0.16–0.20 mm层高。灯罩采用半透明绿色PETG，锥面径向名义壁厚1.2 mm；底圈朝下竖直打印；奶牛镂空上沿按切片预览局部增加可拆支撑，清理时避免支撑粘伤薄壁，尤其保护尾巴弯曲处、乳头附近和腿间的狭窄壁料；小细节的打印还原度需样件验证。透光性依耗材、层高及表面而变。

上、下壳使用银灰PETG。上壳以腰线接合面作为候选贴床面，内侧斜面及座舱接口悬空处按切片预览添加可去除支撑。下壳因灯座高出腰线，不能再以腰线面直接贴床；默认保持灯座朝上，新增半球装饰低于中央底环，不能再让中央底环直接贴床；切片时将整件置于支撑上，底部半球、外圈碟底与中央插颈内孔按预览添加可拆支撑及稳定底筏。半球可见面可能留下支撑痕，需要清理修磨；尚未实际切片或打印。开放分壳便于清理支撑，走线槽口及边缘方形缺口去除毛刺并轻磨圆滑。支撑不得伤及方孔、灯槽及座舱定位面。两枚小方块长度轴竖直打印，0.5 mm导角先进入孔，细筋用于局部修配。8.28/8.3 mm只是名义贴合配合，打印误差可能使其过紧或过松，应先试打一枚方块；修磨细筋或按实测调整方孔。不得强敲或假定插接能承受提拉整灯。

座舱保持定位裙边轴竖直、开口向下；圆顶内侧顶部及宽肩悬垂按切片预览增加支撑。朝上照明选半透明暖黄色PETG。打印后清除毛刺和支撑，竖直放入试配，不应强压。

装配顺序：拆开飞碟上下壳；将发光面向下的灯组放入下壳完整灯座；从上方把引线铺入灯座后侧U形凹槽，在内腔保留弯曲余量后，经下半壳后侧边缘方形缺口向外出线；将两枚方块插入下壳方孔，确认线材低于合壳面且无夹压后合拢上壳，直接放上座舱罩，最后把下壳落到灯罩插颈肩面。更换为朝上照明时，先断电拆开两半，将圆饼灯翻面，整理原引线后重新合壳。
