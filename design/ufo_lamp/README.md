# UFO 飞船灯：上下分壳

船身外径150 mm，灯罩锥体高140 mm、底径114 mm，装配总高206 mm。飞船本体、座舱、绿色灯罩是三个外观组件；按本次要求把飞船本体拆成磁吸连接的上壳、下壳，八个半球推进器均为独立分件，整灯装配为十二个独立打印实体，另有一个同尺寸无镂空备用灯罩，共十三个打印实体，另需四枚圆片磁铁。

## Interfaces

- body_magnet_join：上下盖采用两对磁铁连接，取消两枚独立方块及方孔。每半壳各两个Ø7.1 mm、深1.1 mm圆形盲槽，孔轴沿Z，中心x=±46 mm、y=0，合盖接缝z=156 mm；下槽底z=154.9 mm，上槽底z=157.1 mm。按用户给定尺寸直接建孔，不额外加旷量；磁铁实物与打印尺寸需试配，未选择具体供应商或磁力等级。圆端支座宽14 mm，向中央环填实连接；上座高10 mm，下座底部受外侧锥面限制，不向底面凸出。四个槽底均通过至少2.4 mm实料检查，灯组及出线通道无实体侵入。磁铁建议粘接固定，先核对对应磁极相吸，并使磁铁不高出接合面；吸附力未实测，不通过上盖提起整灯。上下边缘仍各高2 mm、径向壁厚4.8 mm、倒角轴向各高1 mm。
- lamp_fit：灯组包络为用户指定直径60 mm、厚8 mm，安装在飞碟内部z=147–155 mm。承托边与完整定位环均在下半壳，内径61 mm、可用高度9 mm，灯座顶面z=156 mm，与下壳腰线边缘齐平，与座舱平底留16 mm轴向间隙；承托面z=147 mm，中央环外侧台阶已抬平至z=156 mm，环外径74 mm、内径61 mm，内外顶面连续齐平。下壳保留56 mm下照出光口，周围连续封闭，无旧版开放减重腔。圆饼灯两面翻转不改变包络，默认向下照入绿色灯罩；朝上时经中央通道照向座舱，座舱必须用半透明材料才会显著透光。无双向同时照明或光效实测。
- cable：灯座后侧（-Y）保留6 mm宽向上开放平底矩形槽，槽底抬高8 mm至z=152 mm、槽中心z=154 mm；相对于z=156 mm环顶的槽深为4 mm，是下盖外缘2 mm半缺口深度的两倍。内槽合盖后以中心高154 mm、直径3.6 mm圆线包络检查上下壳，均无实体干涉。外部出口位于后侧边缘接缝，默认方口宽6 mm、高4 mm；上下壳各分担2 mm，z=154–158 mm，中心与z=156 mm接缝齐平，沿Y方向贯穿边缘壁。下半口向上开放，上半口向下开放。从上方放线，无需穿插头。出口局部3.6 mm圆线包络检查通过；实际线径和弯曲半径需试装核对。灯罩无走线缺口。
- upper_inner_ledge_flush：上盖内圈台阶沿Z向下延伸13.6 mm，底面由z=169.6 mm降至z=156 mm，与外圈接合面齐平；内壁为连续Ø63.6 mm通孔。内环底面与外圈高度差检查为0 mm；灯组包络、磁铁孔底及出线口检查通过，上下盖无实体干涉。

- dome_drop_fit：座舱罩无向下凸圈，最低面为z=172 mm平整环形承托面。定位凸圈一体设在飞碟上壳，外径68.4 mm、壁厚2.4 mm，从z=172 mm向上延伸5 mm，顶端0.5 mm导入倒角；座舱内部导向孔径69.1 mm、深5.5 mm，单边间隙0.35 mm。罩内导向壁与圆顶融合，不凸出底面。中央通道保持贯通，罩子直接向上取下，无螺纹或锁止；不要抓罩子提整灯。底面与上壳承托面高度差测量为0 mm；两件无实体干涉。默认尺寸待试打印校准。
- shade_insert：灯罩插颈68 mm外径、4 mm长、2.5 mm颈壁，配68.6 mm下壳孔，顶端余量0.8 mm；z=140 mm肩面承载。为重力落座滑动配合，非锁扣；两款灯罩插颈统一缩短为4 mm，以避让下移的灯座，需试装确认短插颈的稳固性。

- underside_decor：下壳底部八个独立半球推进器，半球直径16 mm、高8 mm，中心沿半径60 mm圆周每45°均布，起始角22.5°；球面朝向底部斜面外侧，轴线沿局部锥面法向。后侧出线孔位于两装饰之间。装配中心z=147.3125 mm、最低装饰点z=139.3125 mm，低于下壳中央底环0.6875 mm，与灯罩留有径向空间。

- thruster_insert：每个半球的平圆接触面向内同轴延长直径16 mm、长度1.5 mm的圆柱，零件总长9.5 mm；下壳有八个直径16.5 mm、轴向深1.5 mm的盲孔。深度基准为原半球中心所在的底部局部切平面，孔口沿锥面相交，圆柱端面与孔底相贴。直径间隙0.5 mm，即单边0.25 mm。下壳内侧取消各孔独立圆盘补强，半径42–70.2 mm范围采用法向厚度3.2 mm连续锥形环壁，并向外缘过渡；外侧轮廓及推进器位置不变，每个孔底保留至少1.2 mm实料；源内几何断言验证孔底厚度、插接无实体干涉及灯组/走线空间。间隙定位没有锁止，建议少量兼容PETG的胶固定；实际耗材及打印误差需试配。

- cow_cutout：灯罩正面（-Y）下部按最新黄底黑色奶牛剪影图描取完整轮廓，参考文件为product/references/uploads/20260929T163649070Z-1-ishot-2026-09-30-12-35-28.png。按用户要求左右镜像，使头朝右；保留牛角、耳朵、四条腿、乳房、下垂尾巴和原图轮廓转角。默认旋转前宽32 mm、高约19.88 mm，按原图比例缩放，图案中心x=0、z=38 mm，头朝右上倾斜18°。仅贯穿正面，背面及底圈完整，灯罩保持单一实体。

- plain_shade：额外的无镂空绿色灯罩，基体与shade相同：底径114 mm、顶径76 mm、锥体高140 mm、薄壁1.2 mm；插颈外径68 mm、长4 mm、壁2.5 mm，底圈和肩面完全相同。可替换使用，原奶牛灯罩保留；默认旁置x=160 mm、y=0、z=0，不参与当前整灯装配。

- shade_uniform_wall：两款灯罩外侧锥面尺寸保持一致；以原下端径向壁厚1.2 mm为基准，将内外锥面设为平行。等厚锥壁从z=3 mm延伸至z=138.8 mm，径向1.2 mm、法向约1.191 mm；顶部z=138.8–140 mm为1.2 mm薄承托肩面，连接壁厚2.5 mm的插颈。外形、插颈配合和奶牛轮廓不变。每个基体在五个高度用内核截面面积反算壁厚，并检查两锥面最短距离；断言全部通过，肩面厚度测量为1.2 mm。

## Making and assembly

默认0.4 mm喷嘴、0.16–0.20 mm层高。灯罩采用半透明绿色PETG，锥面恒定径向壁厚1.2 mm（法向约1.191 mm）；底圈朝下竖直打印；奶牛镂空上沿按切片预览局部增加可拆支撑，清理时避免支撑粘伤薄壁，尤其保护尾巴弯曲处、乳头附近和腿间的狭窄壁料；小细节的打印还原度需样件验证。顶部薄肩面跨度约5.45 mm，按切片预览检查桥接或局部支撑；清理时保护1.2 mm肩面。透光性依耗材、层高及表面而变。无镂空备用灯罩同样底圈朝下竖直打印，保留原插颈配合与薄壁设置；没有奶牛镂空局部支撑需求。

上、下壳使用银灰PETG。上壳以腰线接合面作为候选贴床面，内侧斜面及座舱接口悬空处按切片预览添加可去除支撑。下壳灯座顶面已与腰线齐平；默认仍保持灯座朝上、中央底环贴床，外圈碟底、八个倾斜盲孔和中央插颈内孔按切片预览添加可拆支撑。连续加厚环壁与填实连接带增加用料，按切片预览核对填充和支撑。清理时保护盲孔孔壁和孔底。八个独立推进器以圆柱端面朝下、半球朝上单独打印，圆柱轴线竖直；用切片预览确认首层和球面质量。尚未实际切片或打印。开放分壳便于清理支撑，走线槽口及边缘方形缺口去除毛刺并轻磨圆滑。支撑不得伤及磁铁槽、灯槽及座舱定位面。四个磁铁槽先试配实物；选用兼容PETG及磁铁镀层的胶，清除槽底杂物，核对上下对应磁极相吸后再固定。胶层和磁铁不得高出接合面；固化后检查吸附和开合手感，保持力未实测。

座舱以平整底缘贴床、开口向下；内部导向孔轴线竖直。圆顶内侧顶部及导向壁过渡悬垂按切片预览增加支撑，清理时保护导向孔壁和平底承托面。朝上照明选半透明暖黄色PETG。打印后清除毛刺和支撑，竖直放入试配，不应强压。

装配顺序：先试配八个独立推进器与下壳孔位，建议用少量兼容耗材的胶固定并充分固化；拆开飞碟上下壳；将发光面向下的灯组放入下壳完整灯座；从上方把引线铺入灯座后侧平底矩形凹槽，在内腔保留弯曲余量后，经下壳后侧半缺口向外出线；预先粘接的四枚磁铁应已固化，对齐上下两半出线缺口和两对磁铁，确认线材完整位于6×4 mm孔内且无夹压后磁吸合拢上壳，直接放上座舱罩，最后把下壳落到灯罩插颈肩面。更换为朝上照明时，先断电拆开两半，将圆饼灯翻面，整理原引线后重新合壳。

灯组品牌、功率和原配插头未知；仅验证给定机械包络，不指定电气针脚，不改装原电源。首件仍需验证磁铁粘接强度和吸附保持力、座舱落座手感、插颈配合、稳固性和点亮温升。尚无实物测试记录。
